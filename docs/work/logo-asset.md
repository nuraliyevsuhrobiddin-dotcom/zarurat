# Logo asset preparation

The user's attached family/roof/hand gold-blue logo was used as the edit target
with the built-in image_gen tool. A faithful, tightly cropped derivative was
saved to public/images/zaruriyat-logo.png. This is an image-tool derivative,
not the original uploaded binary. No new text or symbols were requested.

Prompt: Preserve the supplied navy rounded square, gold rim, roof/window,
three family figures, gold cupped hand and gold/blue crescents. Retain glossy
gold/blue lighting and proportions; remove excess outer black margin only.
Output a square website PNG, no redesign, added text or objects.

Standard raster resizing produced zaruriyat-logo-192.png, -256.png and
-512.png. The 192px file is used for the header/auth/favicon; the 512px file
is the install icon. The originals remain available in the project.
