# Mobil navigatsiya

Mobil brauzerda har bir asosiy bo'lim o'z hash manziliga ega.
Sahifani yangilash va brauzerning Ortga/Oldinga tugmalari qo'llanadi.

| Bo'lim | Manzil |
| --- | --- |
| Asosiy | #home |
| Xizmatlar | #services |
| Xizmat tafsiloti | #service?category=ID |
| Qanday ishlaydi | #how |
| Oila uchun | #family |
| Yangi murojaat | #request |
| Kuzatish | #track |
| Kirish / ro'yxatdan o'tish | #login / #register |
| Barcha bo'limlar | #menu |
| Maxfiylik | #privacy |
| Kabinet menyusi | #cabinet/menu |
| Hisob sozlamalari | #cabinet/settings |
| Parol | #cabinet/password |
| Murojaat tafsiloti | #cabinet/case?id=ID |

Kabinet bo'limlari oldingi #cabinet/overview, cases, partners, clients,
packages, notifications, team yo'llarini saqlaydi. Ko'rinadigan bo'limlar hisob
roliga bog'liq; haqiqiy ruxsatlar serverda tekshiriladi.

Mobil formalar to'liq sahifada, yuqorida Ortga va pastda navigatsiya bilan ochiladi.
Ilova brauzer va mavjud standalone manifest orqali ishlaydi; bu alohida Android APK emas.
API va shaxsiy ma'lumotlarni offline keshlash qo'shilmagan.
